# Architektura Zintegrowanej Sieci Kurierskiej i Logistyki GDP
## MTC Global Holding | MicroMed Therapeutics

### 1. Moduł API Kurierów (Ostatnia Mila)
* Dedykowane endpointy (`/api/courier/deliveries`) łączące zamówienia e-recept z zewnętrznymi operatorami logistycznymi oraz własną flotą MTC.
* Automatyczne przypisywanie zleceń, harmonogramowanie oraz monitorowanie statusów w czasie rzeczywistym.

### 2. Geofencing i Statusy Dostaw w Czasie Rzeczywistym
* Mapowanie tras dostawy leków konopnych i produktów medycznych zgodnie z rygorystycznymi wymogami GDP (Good Distribution Practice / zimny łańcuch dostaw).
* Monitoring temperatur i lokalizacji GPS pojazdów floty MTC.

### 3. Panel Kuriera (Aplikacja Mobilna / Web)
* Dedykowany widok dla dostawców zintegrowany z systemem bezpiecznej weryfikacji tożsamości pacjenta (NFC, kod odbioru PIN, autoryzacja PESEL).
